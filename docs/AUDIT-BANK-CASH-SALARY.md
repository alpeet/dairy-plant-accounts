### Existing feature locations (quick reference)

- **Bank transactions**: sidebar *Operations → Bank Transactions*; ops `shared/operations/bank.js`; import via *Update Data from Excel* (`BANK RECON` sheet).
- **Cash Deposit**: sidebar *Operations → Cash Deposit*; ops `shared/operations/cash_deposit.js`.

- **Top menu / Help**: application menu bar; Help → User Manual / About.

## Implementation plan (after this report)

1. **Salary importer layout fix** + remove hardcoded employees (bug #9 root cause).
2. **Stable transaction IDs + idempotency** for bank rows (Migration 27: `txn_uid` + unique index, empty-ref content keys, skip-on-reprocess), deposit-no collision fix, UI double-submit guards.
3. **Date-bound defaults**: shared local-time BS today helper replacing UTC/AD `toISOString()` fallbacks across operations.
4. **Cash Deposit section**: surface bank-statement deposits, manual classification (persisted + audited), expected-vs-actual reconciliation panel, summary default fix.
5. **Bank review queue**: classify-on-read so stale `''`-class deposit rows stop vanishing.
6. **Duplicate detection report** (read-only) for all financial tables.
7. **Help → Check for Updates** (GitHub latest release compare).
8. Targeted tests only for the above (existing green suites not re-run wholesale).
